# alexandria

Alexandria is a self-hosted application that lets me browse my e-books (EPUB, PDF, and MOBI).

## Prerequisites

.NET SDK:

```sh
curl -fsSL https://dot.net/v1/dotnet-install.sh | bash -s -- --version 11.0.100
```

## Working on the project

Run the commands from the repository root.

- Start the project: `dotnet run App.cs`
- Open http://localhost:5241
